# VM - Treinamento

O que é Entrada?
  - Também chamado de Input, é todo Dado que entra no Sistema.
  - Exemplo: Dinheiro que entra em um Caixa.
    
O que é Processamento?
  - É todo Dado que é transformado ou passa por um processo. 
  - Exemplo: O dinheiro que entra no Caixa é Cálculado (Processado) 
  
O que é Saída?
  - Também chamado de Output, é todo Dado que depois de processado ele é mostrado para Úsuario.
  - Exemplo: Troco devolvido para o Cliente.


# 1. Calculadora Viana e Moura

Entrada 
  - O usuário escolhe uma operação (somar, subtrair, multiplicar ou dividir) e digita dois números.

Processamento  
  - O programa realiza a operação escolhida com os dois números e, no caso da divisão, verifica se o segundo número é diferente de zero.

Saída 
  - O programa mostra na tela o resultado da operação ou uma mensagem de erro quando a opção é inválida ou ocorre uma divisão por zero.


# 2. Média das Notas

Entrada 
  - O usuário digita uma ou mais notas e pode digitar "fim" para encerrar o cadastro das notas.

Processamento 
  - O programa armazena as notas, soma os valores e divide pela quantidade de notas para calcular a média.

Saída.
  - O programa mostra as notas digitadas, a média calculada e informa se o aluno foi Aprovado ou Reprovado.


# 3. Sistema de Login Viana e Moura

Entrada  
  - O usuário digita seu nome de usuário e sua senha para tentar acessar o sistema.
  
Processamento 
  - O programa verifica se o usuário e a senha digitados correspondem aos dados cadastrados e controla a quantidade de tentativas disponíveis.
   
Saída 
  - O sistema informa se o usuário ou a senha estão incorretos, mostra as tentativas restantes ou exibe a mensagem de boas-vindas quando o login está correto.
